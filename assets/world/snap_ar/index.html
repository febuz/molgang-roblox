This is a template, not a live connection. Snap's Camera Kit Web SDK (@snap/camera-kit) needs credentials that only you can issue:

  1. Create an app + API token at kit.snapchat.com (Snap Developer Portal).
  2. Build a Lens in Lens Studio and note its lens ID + lens group ID.
  3. Put them in snap_config.json, then reload — this page will boot Camera Kit against your webcam and apply the Lens.

See ../PLATFORMS.md for how the world's AR overlay (labels + JEPA trajectories) feeds a Snap Lens. This is not the QuestCameraKit repo (that's Meta Quest).
