## GitHub Pages Setup

This dashboard is automatically deployed whenever changes are pushed to:
- `VIRTUALPC_COMPLETE_STATUS.md` (status updates)
- `docs/` directory changes
- `.github/workflows/deploy-pages.yml` (workflow changes)

### To Enable GitHub Pages:

1. Go to repository Settings → Pages
2. Select **Deploy from a branch**
3. Choose **master/main** branch and **/docs** folder
4. Save

### With Custom Domain:

1. Update the `CNAME` file with your domain
2. Configure DNS A record pointing to GitHub Pages IP
3. GitHub will auto-generate HTTPS certificate

## Auto-Generation

The dashboard is automatically generated by `.github/scripts/generate-dashboard.js` when:
- A commit changes the status file
- GitHub Actions workflow runs
- You manually trigger the workflow

### Manual Generation

```bash
node .github/scripts/generate-dashboard.js
```
