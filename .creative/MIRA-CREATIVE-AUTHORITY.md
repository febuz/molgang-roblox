## 🔄 Asset Workflow

### For Every Asset

```
1. CONCEPT
   └─ Mira sketches/plans the asset
      (2D mockup, 3D preview, sound design, animation storyboard)

2. CREATION
   └─ Mira creates the asset
      (Design tool, 3D software, DAW, animation tool)

3. OPTIMIZATION
   └─ Mira optimizes for performance
      (Compress, LOD, cache, stream-ready)

4. DOCUMENTATION
   └─ Mira documents for developers
      (Usage guidelines, animation curves, audio specs)

5. INTEGRATION
   └─ Mira works with Zip/Luna to integrate
      (Test in legacy, test in Web, iterate)

6. COMMIT TO GITHUB
   └─ Mira commits to the-project/assets/
      (All platforms can access immediately)

7. BROADCAST
   └─ Mira notifies team
      (Asset ready, use this path, no breaking changes)
```
