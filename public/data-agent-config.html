VirtualPC Data Agent Configuration

Configure data-provider tokens and rate-limiting schedules. Settings are stored in data-agents-sidecar/.env and used by the download orchestrator.

API Tokens

Free tier: 250 calls/day @ 5/min. Paid: higher limits.
Free: 25 calls/day.
Usually paid; leave blank if not configured.

Rate Limiting

Downloads are spread over time slots so free-tier limits are respected.

Example: 5 calls/min × 5 min slots = 25 calls/slot. A 250-call/day free tier finishes in ~50 minutes.
