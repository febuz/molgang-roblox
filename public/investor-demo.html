documentation · governance · audit

Every artefact has a lineage.

One Kafka spine carries every chat call, task mutation, and lineage write — 7 topics, real-time audit + cost rollup. A data-governance registry maps every shared JSON file to its owner, schema, license. The Kami skill (open-source) typesets every official document under one editorial design.
