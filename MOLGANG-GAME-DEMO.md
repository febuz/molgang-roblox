## 🚀 Quick Start

### Run MOLGANG Demo

```bash
# Install dependencies (if not already done)
npm install

# Run demo directly
npm run demo:molgang

# Run in headless mode (no visual browser)
npm run demo:molgang:headless
```

1. ✅ Chrome WebDriver initializes
